AES-256-GCM Assembly Split: Implementation Summary
====================================================

Overview
--------
Extracted the AES-256-GCM 8x-unrolled encrypt and decrypt functions from the
monolithic Perl file (aesv8-gcm-armv8-unroll8.pl) into separate Perl files.
This mirrors the approach used in the AES-XTS cleanup and enables incremental
cleanup of the 256-bit functions independently.

Functions moved:
  - aesv8_gcm_8x_enc_256  ->  aesv8-gcm-enc-256.pl
  - aesv8_gcm_8x_dec_256  ->  aesv8-gcm-dec-256.pl

Functions remaining in aesv8-gcm-armv8-unroll8.pl:
  - aesv8_gcm_8x_enc_128
  - aesv8_gcm_8x_dec_128
  - aesv8_gcm_8x_enc_192
  - aesv8_gcm_8x_dec_192
